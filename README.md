# Sagar Chintamani — QA Portfolio

Personal portfolio and learning-in-public page, hosted on GitHub Pages.

Live site: https://sagaryessee.github.io/

## Updating the site

Edit `index.html`, `style.css`, and `app.js`. Images and the downloadable resume live in `assets/`. Push to `main` to publish. No build step or package installation is required. `.nojekyll` keeps publishing static.

For a local preview, run `python3 -m http.server 8765` and open http://localhost:8765/.

## Learning notes

The Playwright learning section is in `index.html` under `id="learn"`. Add notes, examples, and links as they become available.
