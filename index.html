What mobile testing experience do you have?

I contributed to JFH Android and JFM Android/iOS testing, with Android regression automation on emulators, handsets, and tablets. My Android tooling includes Appium, Java, TestNG, ADB, UiAutomator2, screenshots, and per-run logcat capture.

How do you validate APIs and backend data?

I use Postman to investigate API behavior and SQL to verify persistence and data integrity. Checks include missing fields, saved doctor associations, dataset completeness, orphaned rows, session duration, scheduling overlaps, and BP readings.

How do you use AI in QA?

I use AI-assisted tools to develop Python test-data generators and reusable skills for structured QA documents. I also tested an in-app customer-support chatbot for functional behavior and answer relevance and accuracy.
